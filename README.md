# Contexto
Esse projeto visa a criação e instalação de um modelo de analise de dados com inteligencia Artificial. 
Usaremos as plataformas N8n, Kommo CRM com ferramentas chaves no processo. 

# O projeto sera utilizando a Empresa Ficticia Company IG. 
Sera uma empresa que vende serviços de Desenvolvimento de Softaware sob demanda. Com captação de leads atraves de tráfego pago, nas plataformas Meta e Google e possue um total de 10 vendedores. Para isso vamos precisar estruturar o CRM Kommo para tal fim portanto na fasta de infra crm_kommo temos alguns arquivos json para as configurações minimas necessarias para os testes que foram feitos, tambem estaram presentes a base de dados com clientes ficticios em excel para serem importados e usados para os testes.
